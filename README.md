Vibe Coding for Medical Professionals — Companion Materials and Data Files
This repository contains companion materials and data files for the book Vibe Coding for Medical Professionals by George Grätzer.
Companion Materials
Python_Companion.pdf
The Python Companion contains the Python programs used in the book and provides additional explanation for readers who want to examine or modify the code.
Exercise_Help_and_Solutions.pdf
Exercise Help and Solutions provides help, hints, and complete solutions for the exercises in the book.
Exercise_Companion.zip
The Exercise Companion contains the actual program and data files used with the book, organized by chapter. After downloading and expanding the ZIP file, readers can use the files directly rather than reconstructing programs or data from printed material.
Data File
journey_large.csv
A large data file containing 12,000 events for use with the patient-journey application developed in the opening chapters of the book. It allows readers to run the same application on a substantially larger collection of data after first learning it with the small example supplied in the book.
Downloading the Files
Click the file you want, and then use GitHub's Download raw file button (the download-arrow icon) to save the actual PDF, ZIP, or CSV file to your computer.
The companion materials and data files are provided free of charge for readers of Vibe Coding for Medical Professionals.
