Vibe Coding for Medical Professionals — Companion Volumes and a Data File

This repository contains the two companion volumes and a large data file for the book Vibe Coding for Medical Professionals by George Grätzer.

Companion Volumes

Python Companion
Contains the Python programs used in the book.

Exercise Help and Solutions
Provides help, hints, and solutions for the exercises in the book.

Data File

journey_large.csv
A large data file containing thousands of records for use with the patient-journey application developed in the opening chapters of the book. It allows readers to run the same application with a substantially larger collection of data after first learning it with the small example supplied in the book.

The two companion volumes and the data file are provided free of charge for readers of the book.
