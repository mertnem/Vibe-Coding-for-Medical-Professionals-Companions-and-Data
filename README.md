# Vibe Coding for Medical Professionals

## Companion Materials and Data Files

This repository contains downloadable materials for *Vibe Coding for Medical Professionals* by George Grätzer.

### Files

- **Python_Companion.pdf** — Companion volume explaining the Python programs used in the book.
- **Exercises.pdf** — Exercise materials for the book.
- **Chapters.zip** — Chapter folders containing the Python program and corresponding data file for each chapter.
- **journey_large.csv** — Optional data file with 12,000 events for running the patient-journey application on a larger dataset.

### Downloading

Select a file in the list above, then use GitHub’s download button to save it to your computer. After downloading `Chapters.zip`, expand it to access the chapter folders.

These materials are provided free of charge for readers of the book.
