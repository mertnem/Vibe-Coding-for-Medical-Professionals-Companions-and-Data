# Vibe Coding for Medical Professionals — Companion Volumes

This repository contains the two companion volumes for the book
*Vibe Coding for Medical Professionals* by George Grätzer.

## Companion Volumes

**Python Companion**  
Contains the Python programs used in the book.

**Exercise Help and Solutions**  
Provides help, hints, and solutions for the exercises in the book.

Both companion volumes are provided free of charge for readers of the book.
